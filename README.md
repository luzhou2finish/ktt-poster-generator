# 快团团素材生成器（本地版）

第一版单文件静态页面，浏览器直接打开即可使用，不需要安装、不需要服务器、不需要联网。

- 项目规则：`AGENTS.md`
- 入口文件：`index.html`

---

## 本地打开方式

1. 用浏览器直接打开 `index.html`：
   - Mac 双击文件
   - 或在终端运行 `open index.html`
2. 所有图片只在当前浏览器内存里处理，刷新页面后内容会丢失，记得先导出 PNG。

## 未解决的问题

1. **二维码尺寸可能偏小**
   - 当前二维码显示区域为 80 × 80，扣掉 8px 白边后码本身只有 64px。
   - 导出图是 720 × 1280，在真实手机上被缩小时可能扫不出密集码。
   - **需要你提供真实二维码导出后实测**，如果识别困难，再改成 120 × 120（会压缩底部文字空间，但计算过仍有安全余量）。

2. **未做浏览器兼容性测试**
   - 只在 Chrome 155 跑通。如果你常用 Safari 或 Firefox，告诉我，我补测。

3. **未发布到 GitHub Pages**
   - 发布流程：建仓库 → 网页上传发布文件 → Settings 开 Pages → 验证在线链接。
   - 需要你确认文件清单并执行（或授权我执行）。

4. **没有自动保存 / 草稿同步**
   - 按规则第一版不做。刷新页面内容会丢失，这是预期行为。
